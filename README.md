# dsh-vector-memory

[![ci](https://github.com/Streamer-TP-Meteor/Dsh-vector/actions/workflows/ci.yml/badge.svg)](https://github.com/Streamer-TP-Meteor/Dsh-vector/actions/workflows/ci.yml)
[![license: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

给 [DSH](https://github.com/deepseek-ai/deepseek-harness) 的**本地语义记忆层**：把你的笔记、决策记录、项目文档变成可被任意模型直接检索的知识库。

不联网、不上传、不要 API key。检索由本机的 `Qwen3-Embedding-0.6B` 完成，全部计算在你自己的 CPU 上。

```
你的文档 ──▶ 切块 ──▶ 本地向量模型 ──▶ 索引（磁盘）
                                        │
用户提问 ──▶ 向量检索 + BM25 混合 ──▶ 相关片段 ──▶ 模型（自动/按需）
```

## 它解决什么

长对话里，模型的「记忆」只有上下文窗口那么大。窗口一满，早期的决定、踩过的坑、约定好的规范就丢了，模型开始凭印象编。

这个插件做四件事：

1. **把长期知识放在窗口外**：你的 `memory/*.md`、项目文档被切成块，用向量存起来，随时可查。
2. **每轮自动带 3 条**：会话第一句话之后，最相关的那几条会以「【向量检索 · 本机记忆】」的块随请求发出——任何模型、任何子代理都吃得到，不需要它主动调工具。
3. **需要时深挖**：模型可以调 `vmemory_search` 精确检索（约 0.2 秒），拿到带 `文件:行号` 的出处，再回原文核对。
4. **把「以前的会话」也变成可检索的**：插件自己把 DSH 的会话记录归档成 Markdown，切片成卡片进向量库；新会话开头还会带一段「上次聊到哪儿」。所以「上次那个方案」不依赖当前模型记不记得——换个模型、换台机器、跨项目跨盘，都能查回来。

## 功能

| 功能 | 说明 |
|---|---|
| 语义检索 | Qwen3-Embedding-0.6B，1024 维，32K 上下文，中英日等 100+ 语言 |
| 混合排序 | BM25（字 + 双字）与向量结果用 RRF 融合，关键词与语义各补一半 |
| 可选重排 | Qwen3-Reranker-0.6B 精排，默认关闭（CPU 上一次约 6–15 秒） |
| 增量索引 | 按文件内容哈希缓存向量，只算变动的文件；改名挪目录不重算 |
| 按源重建 | 只重建某一个项目/目录，秒级完成（全量重建可能几分钟） |
| 自动召回 | 会话首轮自动注入 top-3，可设条数、相似度阈值、字数上限、超时 |
| 统一检索 | `vmemory_recall` 一次查三处：策展文档 / 会话卡片 / 归档原文，结果分区返回 |
| 会话归档 | 自动把 `~/.dsh/sessions` 里的会话转成可读 Markdown（只留真实发言、助手正文、模型自己写的压缩摘要），增量更新 |
| 开场简报 | 新会话开头自动带「上次会话 · 本项目归档」：同项目最近 3 个会话的标题、诉求、停在哪 |
| 会话卡片 | 手工压缩过的会话生成摘要卡进向量库；跨会话检索实测 Recall@1 从 0% 提到 57% / R@3 71% |
| 按会话开关 | 输入框左侧「记忆」按钮：本会话开/关、四档检索范围、知识块与简报开关，偏好三层继承（会话 > 项目 > 全局） |
| 跨盘项目 | 会话落在哪个目录就自动登记为项目源，D 盘 E 盘 U 盘都一样 |
| 设置页 | 状态 / 检索测试 / 参数 / 项目 / 维护 五个页签，全部可视化 |
| 离线 | 装好之后不需要网络；服务只监听 `127.0.0.1` |
| 随 DSH 退出 | 看门狗盯住宿主进程，DSH 关掉约 3 秒后服务自动退出 |

## 三条检索通道

| 通道 | 内容 | 适合 |
|---|---|---|
| 文档 | `sources` 里登记的笔记/项目文档块（向量 + BM25 混合） | 「我们定过什么方案」「这模块怎么实现的」 |
| 会话卡片 | 历史会话的摘要卡（谁在什么时候聊了什么、结论是什么） | 「上次那个事后来怎么了」 |
| 归档原文 | 归档 Markdown 里的字面匹配（不依赖向量服务） | 记得原话/标识符，要精确出处 |

`vmemory_recall` 会把三条通道并发跑一遍，按「文档 / 会话卡片 / 归档原文」分区返回；卡片命中时自动回原文件取一段原文（两阶段取文），所以命中摘要后不用再手动 grep。任何一条通道坏掉都不会让调用失败——另两条照常给结果，错误单独列出。

## 安装

Windows 上一条命令（不需要管理员）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1 -DataDir D:\vector-memory-data
```

细节、参数、验收与排错见 **[INSTALL.md](INSTALL.md)**；想让 AI 代劳，给它看 **[AGENTS-install.md](AGENTS-install.md)**。

## 怎么用

装好、重启 DSH 之后：

- **什么都不用做**——新会话的第一轮就会带上检索块。想确认：设置 → 向量记忆 → 状态 → 「已注入」计数会增长。
- **让它查以前的决定**：直接问「上次那个方案是怎么定的」，模型会先 `vmemory_search` 再答，并给出 `文件:行号`。
- **想让它看别处的文档**：设置 → 向量记忆 → 项目 → 输入目录 → 添加目录（会自动索引，且召回只在「记忆 + 当前项目」范围内）。
- **调参**：参数页可以改召回条数、相似度阈值、超时、索引的文件类型/大小上限、服务线程数等，改完即时生效（端口/线程改了需要重启服务）。

## 六个工具

| 工具 | 作用 |
|---|---|
| `vmemory_recall(query, k?, srcs?)` | **一站式检索**：文档 + 会话卡片 + 归档原文，约 0.7 秒，结果分区 |
| `vmemory_search(query, k?, src?, rerank?)` | 语义 + 关键词混合检索（只看文档源），返回带出处的片段 |
| `vmemory_archive_search(query, k?)` | 归档会话里的字面检索（多词计分，不依赖向量服务，约 0.1 秒） |
| `vmemory_index(force?)` | 增量索引（`force` 为全量重建） |
| `vmemory_outline(src?)` | 知识地图：某个源里都有哪些主题、各自在哪个文件 |
| `vmemory_status()` | 索引、服务、归档、卡片的状态 |

## 配置文件

`engine/config.json`（`setup.ps1` 生成；完整示例见 [`config.example.json`](config.example.json)）。

最常改的几个键：

| 键 | 含义 |
|---|---|
| `data_dir` | 索引与日志放哪 |
| `python` | 用哪个解释器跑引擎（默认插件目录下的 `.venv`） |
| `models.embed` / `models.rerank` | 模型目录，或 Hugging Face repo id（如 `Qwen/Qwen3-Embedding-0.6B`） |
| `sources` | 常驻笔记目录（`root` + `globs`/`extensions`） |
| `project_index` | 跨盘项目自动登记与索引的开关、文件类型、上限 |
| `recall` | 自动召回的开关与参数（条数/阈值/超时/是否要求模型先看上下文） |
| `handoff` | 开场简报与会话归档（开关、最近几个会话、字数上限、归档间隔） |
| `cards` | 归档卡片的开关、注入条数与打分门槛 |
| `service.allow_remote` | 默认 `false`；改成 `true` 才允许监听非回环地址（危险） |
| `service.recycle_rss_mb` | 重建索引后若服务内存超过这个值就重启服务回收（0 = 不重启） |

## 2.1.0 新增了什么（相对 2.0.0）

这一版跨度较大：从"三个工具 + 文档向量"变成"**一个统一检索入口 + 三条通道 + 会话级开关**"。详细条目见 [CHANGELOG.md](CHANGELOG.md)。

- **统一检索**：新工具 `vmemory_recall` 一次同时查三条通道——文档/记忆（向量）、会话卡片（历史对话摘要）、归档原文（字面精确匹配），结果分区呈现并带 `path:line`。排序经过评测：混排会把会话挤掉（R@3 88%→60%），最终改为分区各自给结果（命中率 96%、R@1 56%、R@3 80%）。
- **会话历史可检索**：把 DSH 会话记录物化成可 grep 的 Markdown（增量、自动维护）；新会话自动注入「【上次会话 · 本项目归档】」；压缩摘要切成卡片进向量库，于是"以前那个会话聊过什么"能语义搜到。
- **会话/项目级开关**：输入框左侧「记忆」胶囊——本会话开关、四档检索范围（自动 / 仅记忆 / 仅本项目 / 全部来源）、知识块开关、开场简报开关、本项目是否参与索引，还能存成项目默认。偏好解析顺序：会话 > 项目 > 全局。
- **稳定性**：并发闸门（默认 6 路，20 路突发也有结果）、内存看守改为按服务自报空闲时间判断、修掉"重启风暴"、检索超时真 abort、索引写入原子化 + 单写者锁。
- **安全**：引擎加 Host / Origin / `Sec-Fetch-Site` 三重护栏与 32MB 体上限；模型下载脚本不拉 `*.py`、支持 `--revision` 钉版本。
- **工程**：一份源码跑开发机与发布包两种场景（`src/paths.js`，不再手工消毒）、零运行时依赖、自带 **13 套 359 项**测试、CI 增加个人路径扫描与打包垃圾门。

## 2.0.2 修了什么（外部审计逐条验证后采纳）

两份独立外部审计对着发布包挑问题，逐条回到代码验证：**为真的照改并补回归测试，验不出来的写明理由不动**。

- **设置页空白**：`/state` 的 async 结果被展开只剩两个字段（1.18.22 引入的回归），设置页五栏与版本徽章都读不到数据。已修，并加冒烟断言「六个顶层键必须都在」。
- **自定义端口失效**：检索/召回传 `null` 配置时回落到默认端口。已改为统一从配置解析（自定义 host/port/并发上限现在真的生效）。
- **取消不生效**：召回的超时预算对 HTTP 通道无效、检索超时不 abort 还会起 python 冷启动。已改为取消即断请求、降级路径不启 CLI。
- **宿主被带走**：`runCli` 在绑 `error` 监听前就提前返回，python 路径写错会崩宿主。已修。
- **索引半新半旧**：五个索引文件逐个直写，进程被杀就坏档。已改为一组 tmp + fsync + 连续 `os.replace`，并加单写者锁。
- **模型加载失败永久摆烂**：现在按 `service.load_retry_sec`（默认 120 秒）自动重试。
- **本机引擎零鉴权**：网页脚本可以跨站打 `/shutdown`、读 `/search`。已加 Host / Origin / `Sec-Fetch-Site` 三重护栏与 32MB 请求体上限。
- **发布包夹带字节码**：`__pycache__` / `*.pyc` 已排除（打包脚本走回收站清理，CI 增加打包垃圾门）。
- **模型下载脚本的供应链风险**：`scripts/download_models.py` 不再下载 `*.py`（恶意权重仓库可用 `trust_remote_code` 里的 .py 执行任意代码），并支持 `--revision` / `HF_REVISION` 钉住 commit。
- **服务被「重启风暴」卡死**：模型加载期 `/health` 返回 `embed:false`，守护任务曾把它当"挂了"反复重启，导致永远加载不完。现在「加载中只等不重启」且并发拉起合并成一次。
- **并发突发会空手而归**：20 路同时检索时，尾部请求排队超时、而该 query 归档又没有字面命中，会返回空。现在默认并发 6、闸门排队 10s、向量预算 16s，并补一次 6s 短重试 → 20/20 都有结果。
- **忙时被回收**：内存看守以前只看宿主自己发起的检索，CLI / 索引 / 另一个实例的请求它看不见，容易在忙时重启服务。现在 `/health` 上报 `last_req_age_s`，按服务自己看到的空闲时间判断。

回归规模：**13 套 359 项**，`node test/run-all.mjs` 一条命令跑完（约 2 分钟）。

## 兼容性

- 插件清单声明 `engines.dsh: ">=0.2.2-rc.0"`：**只有下限，没有上限**。新的 DSH 出来不会因此拦住你；插件会在能跑的前提下继续工作。
- 已在 `0.2.2-rc.2` / `0.2.2-rc.3` / `0.2.2-rc.5` 上验证。
- 版本号规则：`<系列>.<插件迭代>.<DSH 代际>`，例如 `1.8.22` = 系列 1、第 8 次迭代、适配 DSH 0.2.2 一代。只有确认适配新一代 DSH 时才动最后一位。

## 安全

不联网、不上传、不删除文件、不要管理员、不改 PATH。

本机 HTTP 引擎默认只监听 `127.0.0.1`，并校验 `Host` / `Origin` / `Sec-Fetch-Site`：网页脚本无法跨站调用 `/search` 或 `/shutdown`。想改成局域网共享需要显式打开 `service.allow_remote`。完整的能力边界与不设防的部分写在 **[SECURITY.md](SECURITY.md)**。

## 卸载

```powershell
dsh plugin --profile desktop remove dsh-vector-memory
```

再删掉插件目录和数据目录即可。它不写注册表、不装系统服务。
